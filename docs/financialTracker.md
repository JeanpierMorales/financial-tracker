La idea es desarrollar un sistema personal para el registro y seguimiento de mis finanzas, con el propósito de tener un mayor control sobre el dinero que recibo y gasto diariamente. El sistema permitirá registrar de manera sencilla los ingresos y gastos realizados, indicando información como el monto, fecha, descripción, categoría y método de pago utilizado. De esta manera, se busca reemplazar el registro manual y disperso de los movimientos financieros por un único lugar donde pueda consultar toda la información.

El sistema estará orientado principalmente a conocer cómo evoluciona el dinero disponible a partir de un presupuesto o saldo inicial. Cada ingreso representará dinero que efectivamente entra a mi disposición, mientras que cada gasto representará una salida de dinero. Los movimientos podrán realizarse mediante transferencia bancaria, Yape o efectivo, permitiendo además registrar las transferencias realizadas entre mis propias cuentas o medios de disponibilidad de dinero sin confundirlas necesariamente con un ingreso o gasto.

Además del registro de movimientos, el sistema permitirá consultar y analizar el comportamiento de mis finanzas a lo largo del tiempo. La información estará organizada mediante categorías como universidad, transporte, comida, entretenimiento, ropa, tecnología y otros, facilitando la identificación de dónde se concentra el gasto. A partir de estos datos, se busca disponer de una visión clara del saldo disponible, los gastos realizados y la evolución de mis finanzas, utilizando esta información como apoyo para tomar mejores decisiones sobre el uso de mi dinero.
